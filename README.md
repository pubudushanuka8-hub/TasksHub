## TasksHub

This is a simple task management mobile application developed using React Native and Expo.

## Features
- Add and view tasks.
- Store tasks using AsyncStorage.
- Receive local notifications.
- Navigate using tabs and stack navigation.
- Select a profile image from the gallery.
- Save profile details locally.
- Clear stored data.

## Technologies Used
- React Native
- Expo
- TypeScript
- AsyncStorage
- Expo Notifications
- Expo Image Picker
